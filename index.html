Configurar el panel (una sola vez)

El panel guarda los cambios en GitHub con una clave que solo puede editar este repositorio. La pegás acá una vez: queda guardada cifrada con la contraseña de administrador, y después se entra solo con la contraseña.

  1. Entrá a crear una clave nueva (con tu cuenta de GitHub).
  2. En Repository access elegí Only select repositories y marcá carpa-del-encuentro.
  3. En Permissions → Contents elegí Read and write. Creala y copiala.

Sin cambios
