Entrar al panel

Para guardar cambios necesitás una clave de GitHub que solo pueda editar este repositorio. Se guarda únicamente en este navegador.

  1. Entrá a crear una clave nueva.
  2. En Repository access elegí Only select repositories y marcá este repositorio.
  3. En Permissions → Contents elegí Read and write. Creala y copiala.

Sin cambios
Arrastrá el punto hasta la puerta de la iglesia
